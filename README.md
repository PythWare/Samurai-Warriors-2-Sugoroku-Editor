An Editor for the Sugoroku mode in Samurai Warriors 2. Credit goes to God(Christian) and myself for the programming of the Editor. The Editor currently only works for the US version of the PS2 version of Samurai Warriors 2 but you can change the offset in the script to the offset for Property data for the version of the game you want to mod whether it is a different region version of the ps2 version or the PC version of the game. The offset used for the US version of the PS2 game for Property Data is 
64351F0. I included the icons zip file for the Editor. I intended to make a coordinate guider script for Sugoroku mode but I ran out of time. You can mod property data and create custom Sugoroku maps since the editor handles the X and Y coordinates of where properties are in Sugoroku mode.

How To Use:

Make sure you have Python 3 installed.

Ensure the files within this download are extracted and placed in the same directory as the SW2.iso file (you must rename the samurai warriors 2 iso file to "SW2.iso" while using this editor).

Keep a backup of the SW2.iso file, though the Sugoroku Editor does come with a mod manager that supports mod disabling so it'll revert your iso file to an unmodded version (for property data) when you disable a mod.

The file for disabling mods is Sugoroku.SW2D which is stored within the Backup_Mod_Disabling folder, you'll select the file when using the mod manager for disabling mods.

The files "Sugoroku.SW2D", "Sugoroku.SW2R", and file type ".SMOD" are custom files designed by me, it's essential you don't modify them outside of the Sugoroku Editor unless you know what you're doing.

Things to keep in mind:

The Editor will work properly but you must use values that the game supports. If you encounter an issue after applying a mod, check to see if you entered a value the game doesn't support. An example is for property types, there's only a couple different types of properties in SW2 by default so if you enter a value like 101 for Property Type, it will probably crash the game since I think there are only 5 property types (0-4 being the values, so 5 property types).

The large map in Sugoroku mode by default has 80 properties/tiles while the small map has 56 properties/tiles. So slots 0-79 are for the big map in the Sugoroku Editor while slots 80-136 are for the small map.

If you encounter any issues, let me know on here or reddit (my username on reddit is ThatFlowerGamu)
